Ambiente de Teste vs Ambiente Alvo

Este sistema usa GnuCOBOL 3.2.0 para validacao de logica, publicado em AWS EC2 (Amazon Linux). O ambiente de producao alvo e IBM z/OS Enterprise COBOL 6.5 com DB2. Abaixo as diferencas relevantes.

Caracteristica GnuCOBOL 3.2.0
(Este ambiente - AWS EC2)		 IBM z/OS COBOL 6.5
(Ambiente alvo)		 Impacto
Plataforma Windows / Linux (x86-64) z/OS (mainframe s390x) Encoding diferente (ASCII vs EBCDIC)
COBOL Standard COBOL 85/2002 COBOL 85/2002/2014 Nenhum — compativel para programas padrao
EXEC SQL (DB2) Comentado (stub) Nativo (DSNHPC) Critico: SQL nao executa aqui — logica de negocio OK, acesso DB nao testado
EXEC CICS Comentado (stub) Nativo (CICS TS) Critico: Transacoes online nao executam aqui
Object COBOL (INVOKE) Nao suportado Suportado 5 programas afetados (OGEV050D, 433D, 443D, OGAA018D, 640D)
COMP / COMP-3 / COMP-5 Suportado Suportado Atencao: tamanho de COMP pode variar (big-endian vs little-endian)
Encoding de dados ASCII / UTF-8 EBCDIC (CP1047) Comparacoes alfanumericas podem dar resultado diferente
DECIMAL-POINT IS COMMA Suportado Suportado Sem diferenca
REDEFINES flexivel -flarger-redefines-ok Permitido Sem diferenca com flags relaxadas
Copybooks Inferidos + 14 de tela reais Originais (PDS) 215 copybooks de dados pendentes de entrega (ver aba Estrutura de Dados)
Banco de dados SQLite local (99 tabelas) DB2 real Estrutura e massa geradas do codigo-fonte; DDL no dialeto DB2
O que este ambiente valida

VALIDA

  • Logica de negocio pura (calculos, validacoes)
  • Fluxo de controle (IF/ELSE, PERFORM, GO TO)
  • Manipulacao de strings e numericos
  • Comparacao de resultados Original vs Convertido
  • Compilabilidade do fonte convertido
  • Estrutura do programa (DIVISION, SECTION, COPY)
  • Estrutura de dados: DDL DB2 + massa de teste (banco SQLite local)

NAO VALIDA

  • Acesso real a banco de dados (DB2/DMS)
  • Transacoes CICS (containers, commarea)
  • Performance em mainframe
  • Encoding EBCDIC e collation sequence
  • Integracao com JES/VSAM/QSAM
  • Comportamento de runtime z/OS (LE runtime)
